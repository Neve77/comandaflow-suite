# Referências do ComandaFlow

Esta pasta preserva especificações históricas que ajudam a orientar a evolução do produto.

- `especificacao-geral.md`: arquitetura, produto e desenvolvimento.
- `relatorios-pdf.md`: padrão para o gerador de relatórios PDF.
- `especificacao-consolidada.md`: versão consolidada das duas especificações.

Consulte primeiro `especificacao-consolidada.md` ao planejar novos módulos ou alterações arquiteturais.
