# ComandaFlow 2.4.4

## Segurança do Gestor e acesso da equipe

- Sessões autenticadas persistidas no servidor, com validade de oito horas.
- Tela **Quem acessou o Gestor** com funcionário, horário de entrada, última atividade, IP e dispositivo.
- Identificação de sessões online, ativas, expiradas e encerradas.
- Encerramento remoto de qualquer acesso pelo proprietário ou administrador.
- Revogação automática das sessões quando uma conta é desativada, a senha é alterada ou as permissões mudam.
- Conexões em tempo real encerradas junto com a sessão bloqueada.
- Registro de logins aceitos, tentativas recusadas e encerramentos na auditoria.
- Botão para copiar instruções seguras de acesso para a equipe.
- Reforço para que cada funcionário utilize conta, senha e segundo fator próprios.

## Compatibilidade e proteção

- A base de sessões é criada automaticamente na atualização sem apagar os dados existentes.
- Tokens de versões antigas solicitam um novo login após a instalação.
- O IP real pode ser registrado quando o túnel local envia os cabeçalhos de proxy.
- Senhas e tokens não são armazenados na sessão nem exibidos no painel.
