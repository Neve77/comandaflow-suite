# ComandaFlow 2.4.5

## Correção do login do proprietário

- Confirmado que contas com perfil **Proprietário** recebem permissão total (`*`).
- Corrigida a inicialização indevida de uma segunda instância do Gestor.
- O aplicativo deixa de misturar uma interface nova com um backend de versão antiga.
- A porta local só é reutilizada quando o modo e a versão do backend são exatamente os mesmos.
- O Gestor agora registra falhas da interface no arquivo local de diagnóstico, removendo tokens e campos sensíveis.
- A tela de erro permite voltar ao login sem apagar banco, clientes, cobranças ou configurações.
- O teste do pacote confirma perfil de proprietário, acesso total e criação da sessão segura.

## Instalação desta correção

1. Feche todas as janelas do ComandaFlow Gestor.
2. Confirme no Gerenciador de Tarefas que não existe `ComandaFlow Gestor.exe` aberto.
3. Execute `ComandaFlow-Gestor-Setup-2.4.5.exe`.
4. Abra somente o atalho **ComandaFlow Gestor** e entre novamente.

## Arquivos Windows

- `ComandaFlow-Setup-2.4.5.exe`
- `ComandaFlow-Gestor-Setup-2.4.5.exe`
